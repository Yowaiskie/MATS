# Coding Standards

Frontend

- React
- TypeScript
- Functional Components
- Tailwind CSS

Architecture

Feature Based

```
src/
├── app/
├── assets/
├── components/
├── features/
│   ├── attendance/
│   ├── authentication/
│   ├── dashboard/
│   ├── members/
│   ├── reports/
│   └── schedules/
├── firebase/
├── hooks/
├── layouts/
├── lib/
├── routes/
├── services/
├── types/
├── utils/
└── main.tsx
```

Naming

camelCase

PascalCase

No inline CSS

Reusable Components

Always use TypeScript interfaces.

Never use any.

Never duplicate components.
