# Ministry Attendance Tracking System (MATS)

## Project Description

MATS is a web-based attendance management system designed for church ministries.

The system replaces manual attendance tracking with a digital workflow that enables administrators to:

- Manage ministry members
- Create weekly service schedules
- Assign members to services
- Record attendance
- Generate weekly attendance reports
- Export reports as PNG images
- Copy reports as Messenger-ready text

The application is intended for internal ministry use only.

---

## Primary Goal

Provide a fast, organized, and paperless attendance tracking system.
